# PaperRadar 1.3.1 搜索空白反馈修复

2026-10-21 用户报告：关键词“图像退化”，方向“多模态学习”，期刊 Nature/CVPR，点击搜索后界面保持空表。

真实运行日志显示搜索执行了：一次来源返回零条；另一次 OpenAlex 返回 30 条，但筛选后零篇，同时 Semantic Scholar 受到 429 限流。旧界面只在状态栏和日志说明，没有在结果区解释。

## 修复

- 在搜索结果上方显示等待进度、完成数量、实际检索词、来源返回/失败与筛选排除数量。
- 区分无可用来源、所有来源失败、来源无候选、候选被筛选排除。
- 提供“取消期刊限制重搜”“取消方向限制重搜”“仅用关键词重搜”和日志入口；放宽前保留用户条件，点击后只清除选定的限制。
- 为“图像退化”加入 `image degradation / degraded images` 显式检索扩展，补充图像恢复、去噪、去模糊、超分辨率词条；多模态方向接受常见 `multimodal / multi-modal` 表述。
- 未识别的中文不会被声称已翻译，界面明确提示当前按原文检索。

## 验证与限制

七个新增用例先失败复现，修复后 297 项测试通过。包含真实 Qt 鼠标点击搜索、等待后台完成、取消期刊重搜、查看日志按钮验证。

使用隔离数据在真实 GUI 中按截图条件搜索：270 条来源记录合并为 253 篇，组合筛选后为零；保留多模态方向、取消期刊限制后得到 5 篇候选；再取消方向，仅用关键词时得到 186 篇候选。记录与截图保存在任务输出 `search-feedback-live.json`、`feedback-reported-conditions.png`、`feedback-without-venue.png` 和 `feedback-keywords-only.png`。这些是本次索引返回下的检索候选数，不是相关性人工评审或总体召回率，也不证明不存在其他满足原条件的论文。

测试中存在 Semantic Scholar 429，已保留并在界面提示。检索有返回不代表所有来源所有扩展请求均成功；部分成功记录继续保留。数据库仍为 v4，本次不改变结构。

打包与安装结果见本次任务输出 `search-feedback-installation.json`。程序使用新的版本目录并更新桌面入口，旧版窗口不强制关闭，真实文献库不用于自动化验证。
